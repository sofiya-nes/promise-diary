# Дневник обещаний

Приложение для секретаря Стукпостука: учёт просьб к Патрицию, его ответов, сроков и комментариев.

## Как запустить

Открыть файл `index.html` в браузере. Установка зависимостей и сборка не требуются.

## Возможности

- Создание, редактирование и закрытие дел (выполнено, отказано, отменено).
- Просмотр дел за выбранный день, неделю или месяц.
- Поиск по названию, просителю, сути просьбы, ответу и комментариям.
- Комментарии с отметками даты и времени.
- Отображение просроченных дел и управление видимостью закрытых.

Каждое дело содержит название, просителя, суть просьбы, дословный ответ Патриция, дату обещания, срок выполнения, статус и комментарии.

## Проектные решения

**Технологии.** HTML, CSS и JavaScript без сторонних библиотек и сборки. Приложение работает в браузере как одна HTML-страница.

**Хранение данных.** Дела хранятся в `localStorage`, поэтому приложение работает офлайн.

**Обработка повреждений.** Каждое дело хранится отдельно под ключом `promise-diary:case:<id>`. При запуске повреждённые записи пропускаются, а остальные загружаются. Пользователь получает предупреждение.

**Сохранение ввода.** Поля дела автоматически сохраняются как черновик при каждом изменении. Черновик восстанавливается при повторном открытии дела и удаляется после сохранения или отмены. При ошибке введённые данные остаются в форме.
